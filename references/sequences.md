# Secuencias

De Bono no fija una única orden. El Azul elige. Todas las secuencias empiezan y terminan en Azul.

## Catálogo

| Uso | Secuencia | Notas |
| --- | --- | --- |
| Sesión estándar | Azul → Blanco → Rojo → Amarillo → Negro → Verde → Azul | Amarillo antes de Negro para no cegar el valor. |
| Decisión rápida | Azul → Blanco → Negro → Verde → Azul | Omite Rojo y Amarillo largos. |
| Alta apuesta | Azul → Blanco → Rojo → Amarillo → Negro+premortem → Verde → Azul → contra-revisión | No comprimir el Blanco. |
| Auditar una propuesta | Azul → Blanco → Negro → Amarillo → Rojo → Verde → Azul | Negro pronto para fallos materiales. |
| Elegir entre alternativas | Azul → Blanco → Verde → Amarillo → Negro → Rojo → Azul | Verde puede añadir una opción no listada. |
| Generar ideas iniciales | Azul → Blanco → Verde → Azul | No fuerces un veredicto. |
| Buscar solución a un fallo | Azul → Blanco → Negro → Verde → Azul | Negro describe el fallo; Verde repara. |
| Plan estratégico | Azul → Amarillo → Negro → Blanco → Verde → Azul | Empieza por el valor buscado. |
| Feedback breve | Azul → Negro → Verde → Azul | Minutos, no un expediente. |

El Azul puede repetir un sombrero si un hallazgo nuevo lo exige. No hace falta usar los seis si el modo no lo pide.

## Cómo elegir en 20 segundos

1. Si el usuario trae un texto para revisar → `auditoria`.
2. Si hay 2+ opciones explícitas → `alternativas`.
3. Si es irreversible o de alta apuesta → `critico`.
4. Si pide "en 2 minutos" o la decisión es barata de revertir → `rapido`.
5. En cualquier otro caso → `estandar`.

## Profundidad por sombrero

- Azul apertura — corto y preciso.
- Blanco — el más largo si hay datos o lagunas.
- Rojo — el más corto.
- Amarillo y Negro — simétricos en extensión.
- Verde — concreto; pocas opciones buenas superan muchas mediocres.
- Azul cierre — decisión, condiciones, tripwires, pendientes.

No repetir un sombrero para "mejorar la nota" de la recomendación.
